# Fluxo — Android development portfolio

[English](README.md) · [Português](README.pt-BR.md)

**Vinicius Nassif · Android Developer**

Fluxo is an Android application for field sales operations. It brings together customer information, product selection, order entry, local data storage, synchronization, and order-status messages.

This repository presents the application and its engineering decisions. The Android source code is maintained separately and is not included here.

## About my work

I develop and maintain Android applications at Líder Minas (Milani), working on implementation, functional testing, builds, and technical support. I am also pursuing a bachelor's degree in Computer Science.

## Application areas

- Customer lookup and customer details.
- Product catalog and product-group navigation.
- Sales orders, drafts, quantities, and pricing.
- Local persistence and synchronization with company systems.
- Messages that communicate order-processing status.
- Sales reports and an in-app help guide.

## Technology

Kotlin · Jetpack Compose · Material 3 · Room / SQLite · Coroutines · StateFlow · Firebase Cloud Messaging
